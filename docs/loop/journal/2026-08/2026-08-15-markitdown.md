## やったこと

### 構成（v0.2）

```
registry → markitdown → inspection → postprocess
形式判定    変換の本体    何が落ちたか   出力を整える
```

`engine.py` だけが markitdown を知っている（差し替えを 1 箇所で済ませるため）。

### markitdown だけではできないこと＝補完した 4 点

| 補完 | なぜ必要か |
|---|---|
| **落ちた情報の警告** | markitdown はグラフも SmartArt も黙って捨てる |
| **画像の実体化** | markitdown は `data:image/png;base64...` という**印だけ**出す。中身が入っていない |
| **非表示シートの除去** | Excel の隠しシートの中身がそのまま出る。**情報漏洩になる** |
| **表の崩れ直し** | 空ヘッダで実データがずれる、空セルが `NaN` になる |

### 削除したもの

自前のコンバータ 4 本、中間表現（IR）、レンダラ、それらのテスト。

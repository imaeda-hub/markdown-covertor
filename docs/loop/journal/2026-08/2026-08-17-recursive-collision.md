  ```
  | C | 1500.0 || 項目 | 値 |

  | 手入力 | 100.00 |
  ```
  グラフの最終行と手入力表の見出し行が 1 行に連結され、両方の表が GFM として壊れる。
  T-35（グラフの数値の桁揃え）を直そうとして見つけた。**T-35 は行の境界自体が壊れているので、
  桁揃えだけ先に直しても意味がない**と判断し、T-37 として先に起票、T-35 は❄️保留にした。

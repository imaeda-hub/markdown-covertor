## レビュー結果
サブエージェントに差分を独立レビューさせた。

- **Critical（対応済み）**: 最初の実装は「行が連続しているかどうか」を見ておらず、
  本文を挟んだ**無関係な 2 つの番号付きリスト**が連番になってしまう不具合を実際に再現された
  （`1. Item1 / 2. Item2 ... 1. Other1 / 2. Other2` が `... 3. Other1 / 4. Other2` に化ける）。
  同じ理由で、箇条書きの下に番号付きサブリストが 2 つ以上ぶら下がる形（親ごとに独立したリスト）
  でも後続のサブリストの番号が引き継がれてしまっていた。
  → mammoth は本文などで区切られると別のリストとして出力し、その時点で既に "1." から
  振り直されている（実測で確認）。Markdown 上で該当行が**連続していない**ことを検出したら
  カウンタを丸ごと捨てるようにし、`test_nest_lists_does_not_bleed_numbers_across_two_unrelated_lists`
  `test_nest_lists_restarts_a_numbered_sublist_under_each_bullet_sibling`
  `test_docx_two_separate_numbered_lists_each_restart_at_one` で固定した
- 仕様との一致・情報欠落・出力安定性・後方互換については指摘なし

# 変換ルール

「元の資料がどんな Markdown になるか」の一覧。

凡例:
✅ 対応済 ／ 📋 未対応（予定あり） ／ ➖ 対応しない ／ ⚠️ **v0.1 からの劣化**

**担当**の欄は、その挙動を誰が決めているか。
🔧 = markitdown（エンジン） ／ 🛠 = 自前の補完（[03-設計](03-design.md)）

---

## Word (.docx)

| 元の要素 | 状態 | 担当 | Markdown 出力 |
|---|---|---|---|
| 見出し 1〜6 | ✅ | 🔧 | `# 見出し` 〜 `###### 見出し` |
| 本文 | ✅ | 🔧 | そのまま 1 段落 |
| 太字 | ✅ | 🔧 | `**太字**` |
| 斜体 | ✅ | 🔧 | `*斜体*` |
| ハイパーリンク | ✅ | 🔧 | `[表示文字](https://…)` |
| 箇条書き | ✅ | 🔧 | `* 項目` |
| 番号付きリスト | ✅ | 🔧 | `1. 項目` |
| 表 | ✅ | 🔧🛠 | GFM の表。空ヘッダで出た場合は 1 行目を見出しに繰り上げる |
| **画像** | ✅ | 🛠 | `assets/<文書名>/image-<ハッシュ>.png` に書き出して参照（`--no-images` で無効） |
| グラフ・SmartArt | ✅ | 🛠 | 出力しないが**警告する** |
| テキストボックス | ✅ | 🛠 | 中身は落ちるが**警告する** |
| **箇条書きの入れ子** | ✅ | 🔧🛠 | 「箇条書きレベル 2」等の組み込みスタイルは mammoth からは無関係な別リストに見え、そのままだと潰れる。元ファイルのスタイル名から階層を復元し、2 マス字下げ + `*`→`+`→`-` の順で入れ子にする |
| **番号付きリストの入れ子** | ✅ | 🔧🛠 | 字下げに合わせて**階層ごとに 1 から番号を振り直す**。親の続きの番号も正しく引き継ぐ。本文などで途切れた別々のリストは、それぞれ独立に 1 から始まる |
| **引用スタイル** | ➖ | 🔧 | **平文になる**（`>` にならない）。対応しないと決定（Q-07）。読めれば実害は小さいと判断 |
| **表題 (Title)** | ➖ | 🔧 | **平文になる**（見出しにもタイトルにもならない）。対応しないと決定（Q-07）。読めれば実害は小さいと判断 |
| 脚注・コメント | 📋 | — | 無視される |
| 数式 | 📋 | — | 無視される |
| 色・フォント・配置 | ➖ | — | 落とす（Markdown に対応表現がない） |

**出力例**

```markdown
# 背景

社内資料は **Office 形式** と PDF に閉じ込められている。*検索できない*のが最大の問題。

## 課題

* 資料が探せない
* 差分が見えない

| 形式 | 対応 | 備考 |
| --- | --- | --- |
| Word | 済 | 見出し・表 |

![image1.png](assets/資料/image-4275ade7a588.png)
```

**箇条書きの入れ子の出力例**（`test_docx_nested_bullets_keep_their_level` で検証済み）

```markdown
* 親 1
  + 子 1
* 親 2
```

**番号付きリストの入れ子の出力例**（`test_docx_nested_numbered_list_renumbers_by_level` で検証済み）

```markdown
1. 親 1
  1. 子 1
  2. 子 2
2. 親 2
```

## Excel (.xlsx)

| 元の要素 | 状態 | 担当 | Markdown 出力 |
|---|---|---|---|
| シート | ✅ | 🔧 | `## シート名` + 表 |
| セルの値 | ✅ | 🔧 | 表のセル |
| 数式 | ✅ | 🔧 | **計算結果**を出力 |
| **非表示シート** | ✅ | 🛠 | **中身ごと除外し、警告する**（`--include-hidden` で出力） |
| 空セル | ✅ | 🛠 | 空欄（markitdown が出す `NaN` を消している） |
| 空のシート | ✅ | 🛠 | 壊れた表を落とす |
| グラフ・画像 | ✅ | 🛠 | 出力しないが**警告する** |
| 数値の書式 | ⚠️ | 🔧 | `0.6` が `0.60` になるなど、元の書式と変わることがある |
| セル結合 | 📋 | — | 値が複製される |

> **非表示シートの除外は既定の動作。**
> 社内原価などが入っていることがあり、そのまま出力すると情報漏洩になるため。

**出力例**

```markdown
## 売上
| 月 | 金額 | 前月比 |
| --- | --- | --- |
| 1月 | 1200 |  |
| 2月 | 1500 | 1.25 |
```

## PowerPoint (.pptx)

| 元の要素 | 状態 | 担当 | Markdown 出力 |
|---|---|---|---|
| スライド | ✅ | 🔧 | `<!-- Slide number: N -->` のコメントで区切る |
| タイトル枠 | ✅ | 🔧 | `# タイトル` |
| 本文 | ✅ | 🔧 | 平文（箇条書き記号は付かない） |
| 表 | ✅ | 🔧 | GFM の表 |
| 発表者ノート | ✅ | 🔧 | `### Notes:` + 内容 |
| グループ図形の中の文字 | ✅ | 🔧 | 拾われる |
| グラフ | ✅ | 🛠 | 出力しないが**警告する** |
| **画像** | ⚠️ | 🔧🛠 | 図形名で参照されるだけで**実体を出せない**。枚数を警告する。T-24 |
| **箇条書き** | ⚠️ | 🔧 | 記号も階層も付かず平文になる（Word の入れ子潰れとは別の、より大きな問題）。T-32 |

## PDF

> **v0.2 で最も改善した形式。** 罫線のない表も復元できるようになった。

| 元の要素 | 状態 | 担当 | Markdown 出力 |
|---|---|---|---|
| **表** | ✅ | 🔧 | **GFM の表**（罫線がなくても復元される） |
| 段落 | ✅ | 🔧 | 元の切れ目を保つ |
| 折り返された行 | ✅ | 🔧 | 連結される（単語の結合は起きない） |
| 文字のない（スキャン）ページ | ✅ | 🛠 | 空 + **警告**（OCR は未対応） |
| 見出し | 📋 | 🔧 | 認識されず平文になる（PDF に見出し情報が無いため） |
| ヘッダ・フッタ・ページ番号 | 📋 | 🔧 | 本文に混ざる |
| 画像 | ➖ | — | 落とす |

**出力例**（罫線のない帳票）

```markdown
INVENTORY RECONCILIATION REPORT
Report ID: SPARSE-2024-INV-1234

| Product Code | Location | Expected | Actual | Variance | Status   |
| ------------ | -------- | -------- | ------ | -------- | -------- |
| SKU-8847     | A-12     | 450      |        |          |          |
```

## 共通の書式ルール

| ルール | 担当 | 理由 |
|---|---|---|
| 空行の連続を 1 つにまとめる | 🛠 | 差分を安定させる |
| ファイル末尾は改行 1 つで終える | 🛠 | 同上 |
| 見出しは最大 6 レベルで頭打ち | 🛠 | Markdown の上限 |
| 画像は内容のハッシュで命名する | 🛠 | 同じ画像が何度出ても 1 ファイルで済む |
| 画像は `assets/<文書名>/` に分ける | 🛠 | 一括変換で同名画像が上書きし合うのを防ぐ |
| 実体を出せない画像参照は本文から消す | 🛠 | 壊れたリンクを残さない（枚数は警告する） |

## v0.1 からの劣化について

自前実装から markitdown に乗り換えた結果、**良くなった点と悪くなった点の両方**がある。
悪くなった点を隠さないために、この表を置いている。

| 項目 | v0.1（自前） | v0.2（markitdown） | 対応 |
|---|---|---|---|
| PDF の表 | 1 段落に潰れる | **表として復元** | 改善 |
| PDF の段落 | 潰れる | **保たれる** | 改善 |
| Word の箇条書きの入れ子 | 保たれる | 潰れる | **改善**（T-25 完了、階層を復元） |
| Word の番号付きリストの入れ子 | 保たれる | 字下げのみで番号は元のまま | **改善**（T-33 完了、階層ごとに振り直し） |
| Word の引用 | `>` | 平文 | 対応しない（Q-07） |
| Word の表題 | タイトルとして保持 | 平文 | 対応しない（Q-07） |
| PowerPoint の箇条書き | `- 項目` | 平文 | T-32（未着手） |
| PowerPoint の画像 | 未対応 | 未対応（枚数は警告） | T-24（未着手） |

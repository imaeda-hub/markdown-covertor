# 変換ルール

「元の資料がどんな Markdown になるか」の一覧。
表中の出力例は、すべて実際のテストで完全一致を検証している値。

凡例: ✅ 対応済 ／ 📋 未対応（予定あり） ／ ➖ 対応しない（[理由](01-product.md#やらないこと現時点)）

---

## Word (.docx)

| 元の要素 | 状態 | Markdown 出力 | 備考 |
|---|---|---|---|
| 見出し 1〜6 | ✅ | `# 見出し` 〜 `###### 見出し` | スタイル名で判定。日本語 UI の「見出し 1」も認識 |
| 表題 (Title) | ✅ | **本文には出さない**（文書のタイトルとして保持） | `--front-matter` で `title:` に出る。落とした旨を警告。2 つ目以降の表題は段落として残す |
| 副題 (Subtitle) | ✅ | 普通の段落 | |
| 本文 | ✅ | そのまま 1 段落 | |
| 太字 | ✅ | `**太字**` | |
| 斜体 | ✅ | `*斜体*` | |
| 打消し線 | ✅ | `~~打消し~~` | |
| 等幅フォント | ✅ | `` `コード` `` | Consolas / Courier / Menlo などで判定 |
| ハイパーリンク | ✅ | `[表示文字](https://…)` | |
| 箇条書き | ✅ | `- 項目` | 入れ子は 2 スペース字下げ |
| 番号付きリスト | ✅ | `1. 項目` | 番号は階層ごとに振り直す |
| 表 | ✅ | GFM の表（1 行目がヘッダ） | セル内改行は `<br>` |
| 引用スタイル | ✅ | `> 引用文` | |
| 段落内の改行 | ✅ | 改行を保持 | |
| 画像 | ✅ | **既定で `assets/<文書名>/` に書き出す** → `![名前](assets/資料/image1.png)` ／ `--no-images` で無効 | 文書ごとにフォルダを分けるのは、一括変換で同名画像（`image1.png`）が上書きし合うのを防ぐため。標準出力への変換時は置き場所がないので自動で無効になり警告が出る |
| 脚注・コメント | 📋 | （現在は無視） | FR-211 |
| 数式 | 📋 | （現在は無視） | FR-212 |
| 結合セル | 📋 | 値が複製される | FR-213 |
| 図形・SmartArt | 📋 | （現在は無視・警告もなし） | FR-306 |
| 色・フォントサイズ・配置 | ➖ | 落とす | Markdown に対応表現がない |

**入力例 → 出力例**

```
[表題]   提案書
[見出し1] 第 1 章
[本文]   普通と【太字】と《斜体》
[箇条書き] 一つ目
  [箇条書き] 入れ子
```
↓
```markdown
# 第 1 章

普通と**太字**と*斜体*

- 一つ目
  - 入れ子
```
（表題「提案書」は本文に出ない。`--front-matter` を付けると先頭に
`title: "提案書"` として現れる）

## Excel (.xlsx)

| 元の要素 | 状態 | Markdown 出力 | 備考 |
|---|---|---|---|
| シート | ✅ | `# シート名` + 表 | ブックのタブ順を保つ |
| セルの値 | ✅ | 表のセル | |
| 数式 | ✅ | **計算結果**を出力 | Excel が保存した値を使う |
| 数値 `1.0` | ✅ | `1` | 見た目のノイズを減らす |
| 真偽値 | ✅ | `TRUE` / `FALSE` | |
| エラー値 | ✅ | `#DIV/0!` などそのまま | 隠すと誤解を生むため |
| 空セル | ✅ | 空欄のまま位置を保つ | 列がずれない |
| 完全に空の行 | ✅ | 削除 | 書式だけの行を除くため |
| 非表示シート | ✅ | 既定で除外し警告 ／ `--include-hidden` で出力 | |
| 空のシート | ✅ | `（空のシート）` | |
| 見出し行 | ✅ | **自動判定**（下記） | |
| セル結合 | 📋 | 値が複製される | FR-213 |
| グラフ・ピボット | 📋 | 無視 | FR-306 |
| セル書式（色・罫線） | ➖ | 落とす | |

### 見出し行の自動判定

Excel のファイルには「ここが見出し」という情報が無いので、次の経験則で判定する。

**両方を満たすとき、1 行目を見出し行にする**

1. 1 行目に値があり、そのすべてが**文字列**（数値・真偽値・エラーでない）
2. 2 行目以降に**数値などのデータらしい値**が 1 つ以上ある

| 表 | 判定 | 理由 |
|---|---|---|
| `月 / 金額` → `1月 / 100` | 見出しあり | 1 行目が文字列、下に数値がある |
| `田中 / 30` → `鈴木 / 25` | 見出しなし | 1 行目に数値が混じる＝データ行 |
| `田中 / 営業` → `鈴木 / 開発` | 見出しなし | 全部文字列で区別がつかない |
| 1 行だけの表 | 見出しなし | 比べる相手がいない |

見出しなしと判定した場合、GFM は表にヘッダ行が必須なので**空のヘッダ行**が出る。

**出力例**

```markdown
# 売上

| 月 | 金額 |
| --- | --- |
| 1月 | 100 |
```

## PowerPoint (.pptx)

| 元の要素 | 状態 | Markdown 出力 | 備考 |
|---|---|---|---|
| スライド | ✅ | `---` で区切る | `--no-page-dividers` で無効化 |
| タイトル枠 | ✅ | `# タイトル` | |
| タイトルなし | ✅ | `# スライド 3` | 番号で代替 |
| 本文の箇条書き | ✅ | `- 項目`（レベルに応じ字下げ） | |
| 単独のテキスト枠 | ✅ | 段落 | 箇条書き記号がない場合 |
| 表 | ✅ | GFM の表 | |
| 発表者ノート | ✅ | `> **発表者ノート**` + 内容 | `--no-notes` で除外 |
| スライドの順序 | ✅ | 発表順を保つ | ファイル名順ではない |
| 図形内の文字 | ✅ | 箇条書きとして拾う | 位置関係は保てない |
| 画像 | 📋 | 無視 | docx と同様の対応を予定 |
| アニメーション・遷移 | ➖ | 落とす | |

**出力例**

```markdown
# はじめに

- 背景
  - 詳細
- 目的

> **発表者ノート**
>
> ここで事例を話す

---

# 次のスライド
```

## PDF

> ⚠️ **PDF だけは「推測」が入る。** PDF は文字と座標しか持たず、
> 「これは見出し」という情報がファイル内に存在しない。以下のルールは経験則であり、
> 資料によっては外れる。

| 元の要素 | 状態 | Markdown 出力 | 判定ルール |
|---|---|---|---|
| ページ | ✅ | `---` で区切る | |
| 折り返された和文 | ✅ | 1 段落に連結（空白なし） | 行末/行頭が全角文字 |
| 折り返された英文 | ✅ | 1 段落に連結（空白あり） | |
| ハイフン折り返し | ✅ | `docu-` + `ment` → `document` | 行末が `-` |
| 空行 | ✅ | 段落の区切り | |
| `・` `•` で始まる行 | ✅ | `- 項目` | |
| `1.` で始まる**短い**行 | ✅ | `## 見出し` | 40 文字以下かつ句点で終わらない |
| `1.` で始まる**長い**行 | ✅ | `1. 項目`（番号付きリスト） | 上記に当てはまらない場合 |
| `1.2` のような節番号 | ✅ | `### 見出し`（階層は `.` の数） | |
| 文字のない（スキャン）ページ | ✅ | 空 + 警告 | OCR は未対応 |
| 表 | 📋 | 崩れる（行がバラバラになる） | **既知の弱点**。T-05 で対応予定 |
| 段組み（2 カラム） | 📋 | 順序が乱れる | **既知の弱点**。T-05 |
| ヘッダ・フッタ・ページ番号 | 📋 | 本文に混ざる | T-06 |
| 画像 | ➖ | 落とす | |

## 共通の書式ルール

| ルール | 理由 |
|---|---|
| 特殊文字（`* _ [ ] ` \ < >`）はエスケープする | 本文が意図せず装飾になるのを防ぐ |
| 段落の先頭の `-` `#` `1.` はエスケープする | 箇条書き・見出しに化けるのを防ぐ |
| 表のセル内の `|` は `\|`、改行は `<br>` | 表が壊れるのを防ぐ |
| 装飾の前後の空白は装飾の外に出す | `** 太字 **` は装飾として解釈されないため |
| 同じ装飾の連続は 1 つにまとめる | `**太****字**` のような出力を防ぐ |
| コードスパン内はエスケープしない | コードの意味が変わるため |
| 見出しは最大 6 レベルで頭打ち | Markdown の上限 |
| ファイル末尾は改行 1 つで終える | 差分を安定させるため |

# AI からの質問（未回答の台帳）

AI が仕様を決められなかった点を、**回答が出るまでここに残す**場所です。

- 各質問の「**回答**」欄に一言書いてください。書き方は自由です
- 回答が出るまで、AI は**その質問に依存するタスクを実装しません**（推測で作らない）
- 一度書いた質問は、回答が出るまで**同じ質問を何度も聞き直しません**
- 回答済みの質問は「決定の記録」に移り、**なぜそう決めたかの履歴**として残ります

チャットで直接答えてもらっても構いません。その場合は AI がここへ転記します。

# AI からの質問（未回答の台帳）

AI が仕様を決められなかった点を、**回答が出るまでここに残す**場所です。

- 各質問の「**回答**」欄に一言書いてください。書き方は自由です
- 回答が出るまで、AI は**その質問に依存するタスクを実装しません**（推測で作らない）
- 一度書いた質問は、回答が出るまで**同じ質問を何度も聞き直しません**
- 回答済みの質問は「決定の記録」に移り、**なぜそう決めたかの履歴**として残ります

チャットで直接答えてもらっても構いません。その場合は AI がここへ転記します。

### Q-05 PDF の「表は復元できません」警告を、常に出してよいか

- **背景**: PDF は構造情報を持たないため表が 1 段落に潰れるが、**潰れた結果が普通の文章に見えてしまう**。
  実資料（罫線なし表の帳票）で確認したところ、表が 0 個・警告 0 件で「変換成功」に見えていた。
  そこで PDF を変換したとき必ず「表・段組みは復元できません」と伝えるようにした。
- **選択肢**:
  - A. 現状のまま（全 PDF で必ず出す）— 表がない PDF でも出るので、うるさい可能性
  - B. 表がありそうなときだけ出す — 検出方法が無いので、実質は当てずっぽうになる
  - C. 出さない — 崩れたことに気づけない
- **AI の推奨**: **A**。誤検出のない B は今の実装では作れず、C は製品原則（情報を失わない）に反する。
  ただし実際に PDF を変換して「うるさい」と感じたら変える。
- **影響**: 回答が無くても実装は進む（現状 A で動作中）。使ってみた感触を聞きたい。

# フィードバック受付

仕様チェックで気づいたことを、ここに**箇条書きで**書いてください。
書き方は自由です。1 行でも、言い切らなくても構いません。

- 未処理は `- [ ]`、AI が処理したら `- [x]` になります
- AI は毎晩のループの最初にここを読み、**他のどのタスクよりも優先**して対応します
- 意味が取れなかった指摘は、勝手に解釈せず未処理のまま残り、
  [journal](../loop/journal/) に質問が書かれます
- 急ぎの場合は、ここに書かずチャットで直接伝えてもらっても構いません
- **逆方向（AI からの質問）は [QUESTIONS.md](QUESTIONS.md) にあります。**
  回答が出るまで AI はその論点の実装を止めるので、詰まっていたらそちらを見てください

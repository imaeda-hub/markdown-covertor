# test.pdf（2 段組みの論文 PDF）

## 症状

1. **1 ページ目が丸ごと欠落する。** タイトル・著者・要旨が出力に現れず、
   いきなり本文の `## Introduction` から始まる。
2. **段落の切れ目が失われる。** 数ページ分の本文が 1 つの巨大な段落になる。
3. **単語が結合する。** `powerfulagents`、`chatoptimized` のように、
   行末で折り返された英単語が空白なしで繋がる。
4. **脚注・ページ番号が本文に混ざる。** `3We refer to Appendix A…` `2` など。

## 原因

PDF は文字と座標しか持たず、「段組み」「段落」という情報が存在しない。
現在は pypdf のテキスト抽出結果を上から順に読んでいるだけなので、

- 2 段組みだと左右の段が交互に混ざる（このファイルでは 1 ページ目が特に崩れる）
- 行間の広さを見ていないので段落の切れ目が分からない
- 和文向けの連結規則（全角同士は空白なし）が英文の折り返しに誤適用される

## 期待する出力

タイトルが `#`、Abstract / Introduction が `##`、段落が元の切れ目で分かれ、
英単語が壊れないこと。

## タスク

- T-05 … PDF の表・段組みの検出（座標情報を使う）
- T-06 … ヘッダ・フッタ・ページ番号の除去
- 単語の結合は T-05 の中で扱う（行の連結判定を座標ベースにする）

# SPARSE-2024-INV-1234_borderless_table.pdf（罫線のない表を含む帳票）

## 症状

**表が 1 つの段落に潰れる。** 在庫表の各行が繋がり、次のような出力になる。

```
Product Code Location Expected Actual Variance Status SKU-8847 A-12 450 B-07 289 -23
SKU-9201 780 778 OK C-15 +15 SKU-4563 D-22 156 CRITICAL 180 -24
```

品番・場所・数量・差異の対応が完全に失われている。
さらに悪いことに、**崩れた結果が普通の文章に見える**ので、
出力だけを見ても壊れていることに気づけない。

## 原因

罫線がないため、PDF の中では単なる文字の羅列でしかない。
表であることは「同じ x 座標に値が縦に並んでいる」ことからしか分からないが、
現在は座標を見ずにテキスト抽出結果をそのまま読んでいる。

## 現在の緩和策

変換時に必ず「PDF の表・段組みは復元できません」と警告する（FR-309）。
壊れていることには気づけるが、直ってはいない。

## 期待する出力

在庫表が GFM の表になること。少なくとも 1 行 1 レコードに分かれること。
